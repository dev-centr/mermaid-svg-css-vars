= Changelog

== Unreleased

== 0.1.3 — 2026-09-10

* Updated the published Themed SVG dependency to `^0.2.2` so host CSS
  variables recolor Mermaid nodes after stylesheet bindings beat inline
  `!important` fill/stroke.

== 0.1.2 — 2026-09-08

* Added `prepareThemedMermaidSvgDualOutput()` so build scripts can generate
  adaptive and host artifacts atomically through the programmatic API.
* Promoted `--dual-output` as the explicit CLI spelling while retaining the
  `0.1.1` `--mode dual` spelling as a compatibility alias.
* Added output-specific diagnostics and rejected colliding dual output paths.

Details:
link:changelog-details/2026-09-08-dual-output-api.adoc[Dual-output API].

== 0.1.1 — 2026-09-08

* Added `dual` mode to emit standalone-adaptive and host artifacts from the
  same rendered Mermaid SVG.
* Added `--check` freshness verification with a distinct stale-artifact exit
  status for CI.
* Added deterministic `.raw.svg` input naming and explicit adaptive/host output
  overrides.
* Updated the published Themed SVG dependency to `0.1.1`.
* Fixed tag publishing to detect already-published versions without registry
  credentials.

Details:
link:changelog-details/2026-09-08-dual-delivery-artifacts.adoc[Dual delivery
artifacts].

== 0.1.0 — 2026-09-08

* Transferred the project to Dev Centr and changed the unpublished package scope to `@dev-centr/mermaid-svg-css-vars`.
* Added `prepareThemedMermaidSvg`, an explicit-binding adapter over the independent https://github.com/dev-centr/themed-svg[Themed SVG] standard.
* Added the CLI `--manifest` route with generic modes, presets, runtime palettes, paired fixed outputs, and structured diagnostics.
* Made `host` the manifest CLI default for the recommended `<themed-svg>` runtime path.
* Kept `--theme-vars` and its Mermaid-specific rewrite and normalization flags as an isolated legacy compatibility route.
* Pinned the pre-release generic transformer by Git commit.
* Clarified that host CSS variables apply to inline SVG, not external `<img>` resources.
* Preserved the existing Mermaid rewrite, normalization, and preparation APIs.

* Initial release: `rewriteMermaidSvgCssVars`, `normalizeMermaidSvgForWeb`, `prepareMermaidSvgForWeb`.
* CLI `mermaid-svg-css-vars` for mmdc / Mermaid CLI post-processing.
* Docs: why CSS-var *inputs* to Mermaid themeVariables cannot work (khroma derivation); webCompatibility behavior.
